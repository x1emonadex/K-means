# Анализатор кластеризации K-means

Приложение для кластеризации многомерных данных методом k-means с графическим
интерфейсом под Windows. Написано на C++17 на чистом Win32 API без сторонних
библиотек.

## О проекте

Программа загружает набор точек из CSV-файла, разбивает его на заданное число
кластеров алгоритмом k-means и показывает результат в виде четырёх таблиц:
общая информация, характеристики кластеров, распределение точек и статистика
качества. Итог можно выгрузить в текстовый отчёт.

Приложение собрано как один исполняемый файл и не требует установки
дополнительных библиотек или среды выполнения.

## Возможности

- загрузка данных из CSV или TXT с автоматическим определением разделителя
  (`;`, `,` или табуляция) и строки заголовка;
- поддержка точек произвольной размерности (в тестовом наборе — до 500
  признаков и 10 000 точек);
- настройка числа кластеров `k` (2–8), порога сходимости (0.001–0.1) и
  максимального числа итераций (5–500);
- инициализация центроидов методом k-means++ вместо случайного выбора;
- индикатор прогресса, статусная строка и предупреждение о строках с разным
  числом столбцов;
- четыре вкладки с результатами и экспорт полного отчёта в файл.

## Интерфейс

Работа идёт последовательно, шаги подписаны прямо в окне:

| Шаг | Действие |
| --- | --- |
| 1. Загрузка данных | «📁 Загрузить CSV файл» / «🗑️ Очистить данные» |
| 2. Параметры кластеризации | `k`, порог сходимости, максимум итераций |
| 3. Выполнение анализа | «🚀 Запустить кластеризацию» |
| 4. Экспорт результатов | «💾 Экспорт полного отчёта» |

Результаты показываются на четырёх вкладках:

- **📋 Общая информация** — параметры запуска, число точек и признаков,
  количество итераций, общая ошибка SSE;
- **🎯 Кластеры** — размер каждого кластера, процент от всех точек, координаты
  центроида, среднее расстояние, компактность и оценка качества;
- **📍 Точки данных** — распределение точек по кластерам с координатами,
  расстоянием до центроида и статусом;
- **📊 Статистика** — количество точек, средняя квадратичная ошибка, баланс
  кластеров, достижение сходимости и текстовые пояснения к каждой метрике.

## Формат входных данных

Обычный CSV: одна строка — одна точка, один столбец — один признак.

```csv
X1;X2;X3;X4
-50;43;-52;-92
-92;86;21;35
```

- разделитель определяется автоматически: `;`, `,` или табуляция;
- первая строка распознаётся как заголовок, если содержит нечисловые значения,
  и пропускается;
- допускается десятичная запятая — она заменяется на точку;
- нечисловые и пустые значения в строке пропускаются;
- если строки содержат разное число столбцов, программа предупредит об этом,
  но продолжит работу.

## Сборка

Требуется компилятор с поддержкой C++17 и заголовков Win32 API.

**MinGW-w64:**

```sh
g++ -std=c++17 -O2 -municode -mwindows K-means_Kod.cpp -o K-means.exe -lcomctl32 -lcomdlg32 -lgdi32
```

**MSVC:**

```bat
cl /std:c++17 /EHsc /O2 K-means_Kod.cpp /link comctl32.lib comdlg32.lib user32.lib gdi32.lib /SUBSYSTEM:WINDOWS
```

Готовая сборка лежит в репозитории — `K-means.exe`, запускается двойным
кликом, установка не требуется.

## Метрики качества

- **SSE (сумма квадратов ошибок)** — суммарное расстояние точек до своих
  центроидов, чем меньше, тем лучше;
- **средняя квадратичная ошибка** — SSE, отнесённая к числу точек, с текстовой
  интерпретацией;
- **компактность кластера** — насколько плотно точки лежат вокруг центроида,
  переводится в оценку «высокое / среднее / низкое»;
- **баланс кластеров** — примерно равные размеры кластеров или сильный
  перекос;
- **сходимость** — достигнут ли порог изменения центроидов за отведённые
  итерации.

## Экспорт

Кнопка «Экспорт полного отчёта» сохраняет текстовый файл
`kmeans_results.txt` с параметрами запуска, значением SSE, распределением
точек по кластерам с координатами и итоговой статистикой.

## Отчёт с примером расчёта

В `Результат.pdf` разобран полный цикл работы алгоритма на небольшом наборе
(16 точек, 4 признака, `k = 3`): инициализация центроидов, расчёт евклидовых
расстояний по шагам, распределение точек по кластерам, пересчёт центроидов и
проверка условия сходимости. Удобно для проверки понимания алгоритма и как
образец оформления результатов.

## Технологии

- C++17, стандартная библиотека (без внешних зависимостей);
- Win32 API: Common Controls (ListView, Tab, Progress), Common Dialogs;
- `<random>` — `std::mt19937` для инициализации центроидов;
- `<chrono>` — замер времени работы алгоритма.

## Возможное развитие

- чтение данных других форматов и работа с пропусками;
